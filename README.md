# 良乡空气质量联动预测

基于北京房山良乡地区逐小时空气质量与气象数据，分析六种污染物与时间、温度、湿度的（滞后）关系，建立多污染物协同预测模型并换算 AQI，为校园户外活动安排提供前瞻性建议。

## 问题背景

空气质量直接影响校园生活与户外活动安排。PM2.5、PM10、O₃、NO₂、SO₂、CO 的浓度既受排放源变化影响，也受温度、湿度等气象条件制约，且气象影响往往存在滞后（扩散、光化学反应、颗粒物吸湿增长）。围绕三个问题展开：① 解释单一污染物与时间、温度、湿度的关系；② 建立六种污染物协同变化的预测模型；③ 将预测转换为空气质量等级，为良乡校区同学安排活动提供建议。

## 数据

- 2026-01-01 ～ 03-31 逐小时数据（清理重复时刻/重复表头/缺失小时后得到 **2160 条**完整记录）
- 六种污染物浓度 + 温度 + 相对湿度

## 方法与结果

**滞后相关分析**：PM2.5 与温度的最强相关出现在 **12 小时滞后**（r = 0.4835）；PM10 于 15 小时滞后（r = 0.3533）；O₃ 与温度即时正相关，CO 与温度即时负相关。

**联动预测**（多模型对比）：季节性朴素 / Ridge 滞后 / 仅气象 VAR / 联合 VAR / 周期残差混合 VAR / **稀疏 VAR（L1 正则）**。
- 数据存在强 24 小时周期锁相，季节性朴素模型平均 MAE 0.5544 已是强基线；
- 周期残差混合 VAR 通过多变量联合建模提取污染物间扰动传递机制（颗粒物同源性、光化学反应），消融实验相比独立模型 MAE 改进 **71.43%**；
- **稀疏 VAR** 自动筛选显著交叉滞后项：平均 MAE 降至 **0.7103**（较标准 VAR(2) 降低 5.65%），平均 R² 达 **0.9945**；
- 按 HJ 633—2026 换算 AQI，测试集数值 MAE **0.5017**；全期以良～轻度污染为主，首要污染物主要为 PM2.5。

**活动建议**：结合 12 小时温度滞后效应，当前 12 小时温度持续低于阈值时预警午后颗粒物累积风险，建议调整户外活动安排。
